# Filtra.AI — Grok Plugin

Filtra.AI brings reputation analysis and customer-review workflows to Grok through the official Filtra.AI remote MCP server.

## MCP

`https://api.filtraai.com/mcp`

The endpoint currently requires no sign-in.

## Tools

- `auditar_reputacao`
- `gerar_resposta_avaliacao`
- `iniciar_teste_filtraai`
- `sobre_filtraai`

## Data scope

The reputation audit analyzes only reviews supplied by the user. It does not claim access to external review platforms or invent customer information.
